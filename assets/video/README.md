# Project demo videos / Vídeos de demonstração

Add the final MP4 files to this folder using these exact names:

- `refengine-demo.mp4`
- `tccbuilder-demo.mp4`
- `agrisentry-demo.mp4`

The project areas are configured for **1920 × 1080 (16:9)** videos. The site uses `object-fit: contain`, so the full application screen remains visible without cropping or distortion.

Recommended export:

- 1920 × 1080
- H.264 MP4
- 8–20 seconds
- muted demonstration
- no personal, company-confidential or production data
- keep interface text large enough to read
- aim for less than 8 MB per file when possible

The poster images remain visible while the MP4 files are unavailable. Videos start only after the user presses play. Changing projects pauses and resets the previous video.
